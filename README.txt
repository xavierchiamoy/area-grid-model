格子面积模型
============

输入示例：16×12

程序上方只显示：16×12 = 192。
下方自动显示四块格子图：
10×10、6×10、10×2、6×2。

程序界面不会显示拆分等式或展开计算过程。
格子图右侧会显示乘法竖式：先算 16×2=32，再算 16×10=160，最后得到 192。
两条箭头直接把 32、160 与格子图中的对应区域连接起来；箭头上不显示拆分算式，乘积下方也不显示附加算式。

使用方法：
1. 在顶部输入算式，点击“生成格子图”或按回车。
2. 分组按钮可以只显示某一行；对应的竖式乘积会被圈出，竖式不会消失。
3. 再按同一个按钮恢复全部。
4. 点击“保存为图片”可以把当前图和竖式一起保存为 PNG。

支持的乘号：×、*、x、X。
长和宽均需为正整数，最大为 200。
